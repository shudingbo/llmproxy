# 实现LLM 的代理功能

聚合 多个 openai 协议 兼容的 LLM 服务， 统一暴露 openai 协议/ ollama 协议 接口。

- 对外暴露 openai 协议 / ollama 协议 接口。
  - 支持模型列表接口
  - 支持 llm 相关功能接口
- 对内聚合多个 LLM 服务，根据请求参数，选择合适的 LLM 服务。
  - 根据配置文件进行配置，每个 LLM 服务都有一个 unique 的 id。
  - 根据请求参数，选择合适的 LLM 服务。
- 可通过配置文件进行配置（聚合的LLM，对外暴露的接口功能）
- 提供一个简单的页面，可以对配置文件进行管理。 可以查看当前系统工作状态。


## 技术栈

- nodejs
  - express
  - axios
